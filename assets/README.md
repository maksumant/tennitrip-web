# TenniTrip landing-page assets

Add the final app screenshots to this folder with these exact filenames:

- `home-dark.png` — upcoming tournament Home screen
- `season-dark.png` — Season planner
- `recommendations.png` — Discover / Recommended For You
- `travel-dark.png` — tournament travel plan
- `packing-dark.png` — tournament packing checklist
- `weather-week.png` — multi-day tournament weather forecast
- `home-underway.png` — Home while a tournament is under way
- `career-dark.png` — Career summary / ranking screen

Optional later additions:

- `ranking-light.png` — detailed ranking breakdown
- `multiple-players.png` — player management / sharing

The landing page is intentionally usable as a static GitHub Pages site. No build step is required.
